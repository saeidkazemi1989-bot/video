# ریل‌فورج — ReelForge 🎬

**از چند عکس و ویدیو، خودکار یک ریل حرفه‌ای اینستاگرام بساز.**
برش روی ضرب آهنگ، رنگ‌بندی سینمایی، متن و کپشن مناسب، هشتگ و خروجی MP4 آمادهٔ انتشار — همه روی خودِ گوشی، بدون آپلود به سرور.

اپ به‌صورت **PWA + اپ نیتیو اندروید و iOS** (با Capacitor) ساخته شده؛ یک کد، سه خروجی.

---

## ✨ چه کاری انجام می‌دهد؟

| مرحله | کاری که اپ خودش انجام می‌دهد |
|---|---|
| ۱. رسانه | عکس/ویدیو می‌دهی. اپ هر فایل را تحلیل می‌کند: نور، کنتراست، رنگ، شارپنس، حرکت و نقطهٔ جالب کادر. اگر ویدیو از ریلز بلندتر باشد، بازهٔ ۲–۱۲ ثانیه‌ای و مبدأ جذابش را خودش می‌گیرد. |
| ۲. سبک | از بین **۱۲ سبک** (سینمایی، فشن، ورزشی، ویروسی، رترو، نوآر، غذا، سفر، بیوتی، برند، ولاگ و «هوشمند») یکی را می‌چینی — یا حالت **هوشمند** بر اساس تحلیل تصاویرت خودش انتخاب می‌کند. |
| ۳. متن | **هوک** (جملهٔ اولِ توقف‌کننده)، متن‌های روی تصویر، کپشن، CTA و **۲۴ هشتگ** به فارسی/انگلیسی — آفلاین و بر اساس موضوع و لحن انتخابی. با کلید API، کیفیت متن بالاتر می‌رود (اختیاری). |
| ۴. موسیقی | فایل آهنگ (یا ویدیویی که صدا دارد) را می‌دهی. اپ **تمپو (BPM)، شبکهٔ ضرب و نقاط قوی** را با FFT پیدا می‌کند و بهترین نقطهٔ شروع را می‌سازد. برش‌ها دقیقاً روی ضرب می‌افتند. |
| ۵. پیش‌نمایش | پخش زندهٔ ریلز با صدا، نوار زمان با نمایش ضرب‌ها، کلیک روی هر نما و پرش به آن. |
| ۶. خروجی | رندر **MP4 (H.264 + AAC)** با WebCodecs روی گوشی: ۷۲۰p/۱۰۸۰p/۱۴۴۰p، ۳۰ یا ۶۰ فریم، ۹:۱۶ یا ۴:۵ یا ۱:۱ یا ۱۶:۹. ذخیره در گالری، اشتراک‌گذاری مستقیم (در iOS/Android شیت اشتراک با اینستاگرام باز می‌شود) و کپی کپشن با یک ضربه. |

**تدوین واقعی است، نه اسلایدشو:** کاور-کروپ هوشمند با تمرکز روی سوژه، حرکت دوربین (کن‌برنز/پن/زوم-پانچ)، ۱۰ نوع ترنزیشن روی بیت (فلاش، زوم‌بلور، گلیچ، وایپ، لایت‌لیک…)، گرید رنگ با شیدر WebGL، شیک روی ضربه‌های قوی، کپشن کلمه‌به‌کلمه (کاراوکه) و اسلوموشن خودکار وقتی ویدیو کوتاه‌تر از برش است.

## 🚀 اجرا (وب / تست روی گوشی)

```bash
npm install
npm run dev          # http://<IP سیستم>:5173
```

- از موبایل با همان Wi‑Fi، آدرس شبکه را باز کن (اپ روی `0.0.0.0` گوش می‌دهد).
- یا از دکمهٔ «Add to Home Screen» در سافاری/کروم، به‌صورت **اپ تمام‌صفحه (PWA)** نصبش کن.

> ⚠️ **خروجی MP4 به کانتکست امن نیاز دارد**: `https` یا `localhost`.
> اگر با IP لوکال (`http://192.168.x.x`) تست می‌کنی، پیش‌نمایش کار می‌کند اما دکمهٔ رندر MP4 در دسترس نیست — برای تست خروجی از PWA نصب‌شده (https) یا اپ نیتیو استفاده کن.

### تست سریع بدون فایل واقعی
در مرحلهٔ اول دکمهٔ **«✨ نمونهٔ آماده»** چند عکس و ویدیوی سینتتیک می‌سازد (با `MediaRecorder` ویدیو هم می‌سازد) و کل مسیر را می‌شود در ۳۰ ثانیه آزمود.

## 📱 ساخت اپ اندروید

نیاز: Android Studio (یا فقط JDK 21 + Android SDK).

```bash
npm run android:apk          # بیلد خودکار نسخهٔ تستی
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```

یا برای کار گرافیکی و بیلد نهایی:

```bash
npm run android              # build + sync + باز شدن Android Studio
```
سپس در Android Studio: `Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s)`.
برای انتشار در Google Play از `Build ▸ Generate Signed Bundle / APK ▸ Android App Bundle (AAB)` استفاده کن (کلید امضا و AAB لازم است).

## 🍎 ساخت اپ iOS

نیاز: **macOS + Xcode 15+** (ساخت iOS روی ویندوز/لینوکس ممکن نیست).

```bash
npm run ios                  # build + sync + باز شدن Xcode
```
در Xcode: پروژهٔ `App` را انتخاب کن ▸ تب *Signing & Capabilities* ▸ تیم اپل خودت را بگذار (یک اپل‌آیدی رایگان برای تست روی گوشی خودت کافی است) ▸ روی گوشی Run بزن. برای توزیع در App Store به حساب Developer (۹۹ دلار در سال) نیاز داری.

## 🧠 چطور «خودش» متن پیدا می‌کند؟

دو لایه:

1. **آفلاین (پیش‌فرض):** دستهٔ محتوا از روی موضوع/توضیحی که می‌نویسی تشخیص داده می‌شود (۱۳ دسته)، سپس هوک، متن روی تصویر، کپشن، CTA و هشتگ‌ها از کتابخانهٔ متنی حرفه‌ای (فارسی + انگلیسی) با لحن انتخابی ساخته می‌شوند. هیچ داده‌ای از گوشی بیرون نمی‌رود.
2. **با کلید API (اختیاری):** در ⚙ تنظیمات، سرویس سازگار با OpenAI را وصل کن (OpenAI / OpenRouter / Groq / سرور خودت). متن‌ها با مدل نوشته می‌شوند و گزینهٔ **«زیرنویس خودکار از گفتار»** (Whisper) هم فعال می‌شود. کلید فقط در حافظهٔ خود دستگاه ذخیره می‌شود.

## 🎵 چطور آهنگ مناسب پیدا می‌شود؟

اپ برای هر فایل صوتی: STFT با هپ ۵۱۲ → شارژ طیفی کل‌باند + باند بم (کیک) → اتوکورلیشن برای تمپو (با درون‌یابی زیر-فریمی) → جست‌وجوی فاز با وزن کیک → برازش مقاوم Theil–Sen روی پیک‌های آنست → شبکهٔ ضرب با دقت زیر ۵ میلی‌ثانیه. سپس طول ریلز به تعداد کامل ضرب گرد می‌شود و نقطهٔ شروع روی ضرب و «بهترین بخش آهنگ» (پرانرژی‌ترین پنجره + نقطهٔ دراپ) تنظیم می‌شود.

> در نسخهٔ فعلی، آهنگ را کاربر انتخاب می‌کند (تا مسئلهٔ کپی‌رایت حل باشد) و اپ آن را روی بیت کات می‌کند. آهنگ‌های پیشنهادی/تولیدشده روی دستگاه در نقشهٔ راه آمده است.

## ⚙️ نکات فنی و محدودیت‌ها

- **پشتیبانی مرورگر:** رندر MP4 نیاز به WebCodecs دارد → Chrome/Edge 94+، Safari 16.4+ (iOS 16.4+)، Chrome اندروید. در مرورگر قدیمی، پیش‌نمایش و متن‌ها کار می‌کنند.
- **همه‌چیز روی دستگاه** پردازش می‌شود؛ آپلود/سروری وجود ندارد.
- برای ویدیوهای ۴K و ریلزهای ۶۰ ثانیه، حجم حافظه بالاست؛ اپ تصاویر را برای تحلیل کوچک می‌کند و PCM را فقط تا پنجرهٔ ۳ دقیقهٔ آهنگ نگه می‌دارد، اما روی گوشی‌های قدیمی‌تر رندر طول می‌کشد.
- HEIC: در iOS/سافاری بومی خوانده می‌شود؛ در بعضی مرورگرهای دسکتاپ ممکن است پشتیبانی نشود (پیام خطا نمایش داده می‌شود).
- فایل‌های بزرگ از گالری مستقیماً به‌صورت Blob استفاده می‌شوند (بدون کپی اضافه).
